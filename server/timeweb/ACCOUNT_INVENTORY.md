## Выявленный риск

До остановки существующий Flask показывал SQL-редактор без входа в учётную запись. Один безопасный запрос `SHOW TABLES` через публичный интерфейс выполнился; изменений в БД не было. Редактор видел таблицы с пользователями и чатами. Проверка после паузы: панель Timeweb показывает «Остановлен», публичный адрес SQL-редактора возвращает HTTP 502. Исходник Flask изучен отдельно в локальной закрытой копии; перед возобновлением надо удалить открытые административные маршруты, перенести и сменить пароль БД, затем проверить права.

Действующее правило Firestore всё ещё допускает чтение и запись всех документов любым вошедшим пользователем. Публиковать более строгие правила без проверки совместимости со старыми клиентами нельзя: это может сломать профили, чаты и платежные операции. Временное Storage-правило блокирует только запись без входа; доступ между вошедшими пользователями ещё не изолирован.

- Ограничение доступа к Firebase снято 2026-09-30. Запросы к Auth/Firestore/Storage подтверждены, но полноценный экспорт и сверка связей данных не выполнены.
- В аккаунте нет готового изолированного сервера/API и приватного S3 для CLRS. Создана только пустая отдельная БД `clrs_staging`; доступ к ней для CLRS ещё не настроен. Платные ресурсы не заказаны.
- Резервные копии существующего MySQL выключены. Это отдельный риск для старого Flask; включение резервирования нужно планировать с учётом стоимости и владельца данных.
- Рабочий APK на Timeweb пока невозможен: Flutter-клиент напрямую обращается к Firebase Auth, Firestore и Storage. Переключателя URL недостаточно; требуется серверный контракт и адаптация клиента.
- Владелец подтвердил: платные ресурсы пока не заказывать, существующий Flask оставить остановленным. Эти ограничения сохраняются.

**Расходы:** без чтения текущего тарифа/счёта Timeweb нельзя обещать нулевое увеличение ежемесячных платежей. Может потребоваться более высокий тариф MySQL или S3, больше исходящего трафика и резервирование. Ничего из этого не заказывать и не включать автоматически; сначала проверить параметры имеющихся услуг и согласовать безопасный вариант для старых данных.

Исходящий трафик S3, увеличение дисков и дополнительные бэкапы не включены. Баланс аккаунта в момент просмотра около 1 409 ₽. Владелец решил пока не заказывать платные ресурсы. Новая VPC создана без сервера, БД и хранилища; существующая сеть старого Flask не является изоляцией нового контура.
