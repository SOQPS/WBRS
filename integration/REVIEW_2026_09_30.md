## Обязательные открытые gates

- **Approved gifts:** нет шести утверждённых фото-оригиналов из [макета](../../CLRS_Codex_QA/work/reference_extract/part2_r623_image62.png): кофе/круассан, дом, Tesla, чёрный G-Wagon, букет, кулон «Вместе». Существующие 2/3/4/5/17.png — прежние иллюстрации; кулон отсутствует. [Ранний integration review](REVIEW_1_0_25.md) фиксирует замену 29 надписанных PNG caption-free версиями; это не точное совпадение с шестью утверждёнными фото. Новые изображения не генерировались.
- **Стена Ксюши:** независимая работа не подтверждена ссылкой/коммитом. По разрешению пользователя работа продолжается без её идентифицированной версии; нашу стену нельзя выдавать за её реализацию.
- **Новая APK:** picker/мануал включены в +42; SHA и source указаны выше. На sandbox42 реальная Gboard больше не вызывает прежний overflow42px: header/list/footer в общей прокрутке, выбранный собеседник и обе кнопки доступны, правая треть фона видна. Gift-send/payment/live user writes не выполнялись. Мануал native проверен на +41, его код не менялся. Прежний ANR +41 не локализован; в ограниченном +42 проходе нового ANR не было, это не подтверждает исправление исходной причины.
- **Publish:** draft PR/source handoff, merge, store signing и публикация — разные этапы. Review APK подписан Debug; сверка и сборка не подтверждают production acceptance.
- **Timeweb:** APK продолжает использовать Firebase. Схема, encrypted exports, read-only API и профильная проекция — отдельный незавершённый этап; live profile/login, все домены/media, final-sync и переключение требуют проверки. Актуальное состояние: [Timeweb README](../server/timeweb/README.md), [auth gate](../server/timeweb/AUTH_MIGRATION_GATE.md), [profile projection](../server/timeweb/PROFILE_PROJECTION.md). Этот UI handoff не утверждает завершение переезда.

Функциональный код, доказательство конкретного APK, точное принятие дизайна, production authorization и миграция имеют разные уровни подтверждения; все замечания одним статусом «готово» не закрыты.
